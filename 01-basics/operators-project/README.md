# Simple Python Calculator 🐍

A beginner-friendly calculator built using Python. This project allows users to perform basic mathematical operations by entering two numbers and selecting an operator.

## 📌 About the Project

This is one of my first Python practice projects, developed as part of my journey to strengthen my programming fundamentals.

The goal was to apply the Python concepts I had learned through practical implementation rather than simply reading about them.

## ✨ Features

The calculator supports the following mathematical operations:

| Operator | Operation |
|---|---|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `%` | Modulus (remainder) |
| `**` | Exponentiation |
| `//` | Floor division |

Additional features:
- Accepts decimal and whole numbers.
- Removes unnecessary spaces from operator input using `strip()`.
- Handles division by zero.
- Identifies unsupported operators.
- Displays calculations and their results.

## 🚀 How to Run the Project

1. Clone this repository:

   git clone YOUR_REPOSITORY_URL

2. Open the project folder in Visual Studio Code.

3. Run the Python file:

   python main.py


4. Enter the first number, the operator, and the second number when prompted.

## 💻 Example Usage

Enter first number 20
Enter operator +
Enter second number 5
20.0 + 5.0 = 25.0

Example with division by zero:

Enter first number 10
Enter operator /
Enter second number 0
Invalid operator!
